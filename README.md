# CourtDesk

CRM-оркестратор поиска и мониторинга судебных дел РФ. Рабочий стол юриста.

Объединяет **CourtSniffer** (поиск дел по номеру/участникам) и **CourtFlow** (мониторинг изменений по делам) в единый интерфейс с подсказками сценариев, хранением состояния и интеграцией с внешними CRM.

## Возможности

- **Поиск дел** — по номеру, ответчику, истцу на всех порталах ГАС «Правосудие»
- **Мониторинг** — отслеживание изменений по делам, новые события
- **Сценарии** — интеллектуальные подсказки после каждого действия
- **Уведомления** — при вступлении решения в силу, новых событиях, истечении сроков
- **Интеграция** — webhook во внешние CRM (1С, Битрикс24, самописные)

## Архитектура

```
CourtDesk (REST API + Storage)
    │
    ├── CourtSniffer — поиск дел
    └── CourtFlow    — мониторинг дел
```
