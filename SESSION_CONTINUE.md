### 2. Ключевые изменения в последней сессии (CR8-CR9)

**CR8 — Captcha & Search:**
- Captcha для всех `.sudrf.ru` (district/appeal/cassation). Использует Puppeteer + RuCaptcha, цифровой режим (`numeric: 1`).
- Два режима: msudrf (AJAX, `waitForNetworkIdle`) и sudrf (form submit via checkForm, `waitForNavigation`).
- Исправлен `case_type` для appeal: `0` (не `1`). Добавлен `new: '5'` для апелляции (не `0`).
- CP1251 декодинг: ручной percent-декодер вместо `decodeURIComponent()`.
- `parseResults` проверяет `<div id="error">`.
- Полная карточка дела в UI (участники с ИНН/КПП/ОГРН, события с судьёй/временем, идентификаторы).

**CR9 — Court Hierarchy:**
- `core/courts.ts`: `findHigherCourt()`, `COURT_HIERARCHY` (`MS→RS→OS→KJ`).
- `CASSATION_MAP`: 89 регионов → 9 кассационных судов.
- `saveMsToRsMapping()`: кэш MS→RS на диск (`court-hierarchy.json`).
- `WatchedCase.enforcedAt`: grace period 90 дней для перепроверки `legalForceDate`.
- `processOne` в оркестраторе: поиск в вышестоящей инстанции по УИД через `searchByCaseUid`.
