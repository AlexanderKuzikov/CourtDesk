# CourtDesk для юриста — материал к встрече

> 2026-07-24 · v0.4.0 · формат: обсуждение

---

## Что это за 30 секунд

CourtDesk — веб-приложение, которое само ходит на сайты судов (sudrf.ru, msudrf.ru) вместо вас. Вы открываете один экран вместо пяти вкладок судов. Система запоминает ваши дела и сама проверяет, не появилось ли решение, не вступило ли оно в силу.

**Главное:** вы не забываете про сроки и не тратите время на рутинные проверки.

## Что уже можно делать

### Дашборд — главный экран (`/`)

Открываете браузер → видите картину:

```
┌─────────────────────────────────────────────────────┐
│  🟦 В мониторинге    🟨 Ожидают      🟩 Решение    🟪 Вступило     │
│       45              12             8              2 (сегодня)    │
└─────────────────────────────────────────────────────┘

Дела в мониторинге
┌───────────┬────────────┬──────────┬─────────────────┬────────────┐
│ Номер     │ Статус     │ Суд      │ Результат       │ Вступление │
│ 2-1234/24 │ monitoring │ Ленинский│ —               │ —          │
│ А56-789/2 │ decision   │ Кировский│ Иск уд. част.   │ 2026-08-15 │
│ ...       │            │          │                 │            │
└───────────┴────────────┴──────────┴─────────────────┴────────────┘

[+ Новое дело]  [🔄 Обновить]
```

Четыре числа вверху — ваш «пульс». Таблица ниже — все дела. Кнопки — добавить дело и обновить.

### Поиск — найти дело (`/search.html`)

Левая панель: выбор суда (по названию или коду) + режим поиска:
- **По номеру** — знаете номер дела (`2-1234/2024`)
- **По участникам** — знаете ФИО, но не номер

Правая панель — результаты. Клик по строке — подробности дела.

### Какие суды поддерживаются

| Тип суда | Откуда берём | Капча |
|----------|--------------|-------|
| Районные | sudrf.ru | Нет |
| Апелляция | sudrf.ru | Нет |
| Кассация | sudrf.ru | Нет |
| Мировые | msudrf.ru | Да (автоматически, за наш счёт) |

### Автоматический мониторинг

Добавили дело → система сама:
1. Заходит на карточку дела (периодически)
2. Видит новое событие → добавляет в историю
3. Появился результат → меняет статус на `decision`, уведомляет
4. Дата вступления настала → статус `enforced`, уведомляет
5. Ошибка при проверке → статус `error`, повторяет автоматически

**Вы не запускаете проверку вручную.** Система работает сама (по расписанию).

## Честно: что не работает или работает частично

| Проблема | Влияние на вас | Статус |
|----------|---------------|--------|
| **Поиск (`search.html`) сейчас сломан** | Нельзя найти дело через UI | Чиним первым (ошибка в адресах API) |
| **Нет отдельной страницы дела** | Карточка — только popup при поиске. Нет истории изменений | Проектируем |
| **Нет автозапуска мониторинга** | Кто-то должен нажать «Запустить проверку» | Добавляем встроенный cron |
| **Нет фильтров в таблице дел** | При 100+ делах — неудобно | Добавляем поиск/сортировку |
| **Нет экспорта** | Нельзя скачать список дел в Excel | По запросу — 2 часа работы |
| **Нет архивации из UI** | Завершённые дела захламляют список | Кнопка «Архивировать» — 1 час |
| **Нет уведомлений вне браузера** | Надо заходить в систему, чтобы увидеть изменения | Telegram / email — по запросу |
| **Нет заметок к делам** | Не оставить комментарий «позвонить клиенту» | По запросу |

## Чего НЕ будет (границы продукта)

- CourtDesk **не подаёт иски и не пишет в суд**. Только читает публичные данные.
- CourtDesk **не заменяет 1С**. Он не ведёт клиентов, договоры, документы.
- CourtDesk **не гарантирует 100% точность**. Если сайт суда поменялся — данные могут задержаться. Система уведомит об ошибке.
- CourtDesk **не работает офлайн**. Данные с судов приходят через интернет.
- Мировые суды **требуют решения капчи** — это занимает 10–30 секунд на дело. Мы платим за сервис решения капчи (включено).

---

## Что важно понимать

1. **Система не умнее сайта суда.** Она берёт данные оттуда же, откуда и вы. Но делает это автоматически и не забывает.
2. **Задержка — нормальна.** Мы проверяем дела раз в несколько часов, не в реальном времени. Если на сайте суда появилось решение 5 минут назад — мы узнаем при следующем прогоне.
3. **Мировые суды — медленнее.** Капча + специфика сайта. Районные суды — быстрее.
4. **История сохраняется.** Даже если вы архивировали дело, данные о нём остаются (можно вернуть).
